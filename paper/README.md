# Companion technical note, version 2.0

The revised note explains how a credited recent OpenAI all-degree-sequence
operator theorem becomes a usable conditional error budget for existing ordinary
undirected Curveball. It retains the mathematical derivation and historical 0.1
executions, and adds the current planner, descriptive studies and separately scoped
formal/certificate tools. The source is standalone LaTeX with inline references.
`provenance.json` binds the revised source and rendered PDF after final review.

This is a technical note, not peer-reviewed acceptance, a new chain, an empirical
speed/accuracy advantage, a finite seeded-law proof or a priority claim. OpenAI
receives source-theorem credit; existing Curveball, heat-bath theory, spectral-to-TV
conversion and rank tests receive separate attribution. The source and PDF remain
**CC BY 4.0**; software remains Apache-2.0. See [LICENSE.md](LICENSE.md).
