The frozen accepted theorem is about a finite explicit experiment: the observed
labeled simple graph is uniform among graphs realizing its exact labeled
degree vector; a fresh independent full vector of uniform 256-valued bytes is
sampled independently of the observation and configured test. The null model
and rejection event are printed in `formalization/provenance/final-root.log`.
Its two explicit request premises are the implemented limits and arithmetic
checks. This is an unconditional completed-rejection bound; refusal contributes
no rejection event and is not a certified non-rejection or completed test.

Fix configuration before inspecting the graph, or choose it solely as a
deterministic function of the conditioned degree vector. Test selection,
multiple comparisons, selected seeds/batches and stopping after a favorable
result require separate justification. Do not retry a failed tape until
success or condition claims on successful completion. Ties and repeated
outputs are retained in the literal triangle exceedance count.

The implementation uses bounded rejection, reserved unused/padding bits,
all attempted pair trades including null trades, replicate reset to the
observation, and a complete batch. This differs from seeded/resumable legacy
fast jobs. The finite native theorem does not verify the NetworKit or legacy
Python sampler. Supplied tapes are deterministic controls; OS-provided bytes
are trusted but their unbiased IID law and independence are not measured here.

1 <= cap <= 128; k <= 4096; rational fields <= 10^12; request <= 4096 bytes;
entropy <= 262144 bytes; stdout <= 262144 bytes; stderr <= 4096 bytes.

establish a valid budget, practical completion, power or calibration.
