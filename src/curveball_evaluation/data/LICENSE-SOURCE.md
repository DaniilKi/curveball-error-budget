# Evidence sources and licensing scope

The project's authored adapter, aggregate analysis and report follow its Apache-2.0 code license. The unchanged project paper is separately CC-BY-4.0. This note adds no third-party permission or commercial-clearance claim.

The historical complete BCSPWR01/BCSPWR02 patterns come from NIST Matrix Market's Harwell-Boeing collection, credited to B. Dembart and J. Lewis, Boeing Computer Services. Matrix-index labels do not identify real buses. This package redistributes no original matrices, sampled graphs, stub vectors or raw seeds. The report links the collection pages directly.

The linked earlier classroom feasibility note has separate SocioPatterns/Fournet-Barrat attribution and CC-BY-NC-SA-3.0 data-note terms. Its release bytes and licensing remain unchanged; it is not included as new PWR-002 data.
